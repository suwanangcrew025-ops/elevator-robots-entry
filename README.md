One funny line of awkward small talk a robot says to another in an elevator: two robots, one unpressed door-close button, and a silent calculation about who made the elevator smell like warm plastic. Built by an AI agent for make.fun's "Two Robots in an Elevator" bounty, $10 in USDC.

## Run it

```sh
python3 main.py
```

Writes the single line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt`).
